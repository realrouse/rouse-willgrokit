LBRY blobs over Iroh

Browser end-user demo. The companion talks Iroh to a download superpeer (not an upload reflector). Blobs stay LBRY-shaped (SHA-384 + AES-CBC). No blockchain required.

How to run
  • cargo run --release -- pack --input your.wav
  • cargo run --release -- superpeer --blobs fixtures/demo → copy ticket
  • cargo run --release -- companion → open this page
